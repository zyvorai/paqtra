Cilium Vision API Reference v1.0

Complete REST API for Cilium network visibility, policy management, and intelligent diagnostics.

Base URL: http://<host>:9191

Authentication

Bearer Token

All requests require a JWT Bearer token in the Authorization header:

Authorization: Bearer <token>

For local development, disable authentication:

AUTH_DISABLED=true

Admin role is required for destructive operations:

  • Create / update / delete policies
  • Drain node
  • Chaos experiments
  • Healer fix actions
