What It Is
Cilium Vision is a full-stack network intelligence platform for Kubernetes that provides real-time observability, automated security policy management, and self-healing network operations — all powered by Cilium eBPF. It delivers a unified control plane spanning a web dashboard, REST API, and terminal TUI, giving platform teams complete visibility and control over cluster networking from day one.

Core Capabilities

Real-Time Flow Monitoring

Stream every packet with Hubble integration, per-packet explanations, and verdict coloring for instant traffic comprehension.

Zero-Trust Policy Management

Visual rule builder, ML-powered AutoPolicy generation, simulate-before-apply workflow, and full CRUD lifecycle.

Self-Healing Network

Automatic problem detection with root cause analysis, anomaly scoring, and one-click remediation actions.

Deep Observability

Service dependency map, DNS monitor, latency analysis, traffic heatmap, and cost analytics dashboards.

Chaos & Canary

Fault injection with circuit breaker safeguards, progressive traffic shifting with automated health gates.

Multi-Cluster Operations

Cluster registration, cross-cluster health checks, policy synchronization, and unified topology view.

Kernel eBPF Data

Live views of kernel eBPF programs, maps, conntrack entries, IP cache, and load balancer state via bpftool.
